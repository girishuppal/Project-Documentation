## Chart Types
---


|Chart Type | Description |
|---|---|
|**Bar Chart**| is a data visualization that uses rectangular bars to compare categorical data|
|**Column Chart**| is a data visualization tool that displays numerical values as vertical rectangles (columns) across different categories |
|**Line Chart**|a data visualization that displays information as a series of data points (markers) connected by straight line segments |
|**Pie Chart**| is a circular graph that shows how a total amount is divided into proportional parts|
|**Donut Chart**|  is a variation of a pie chart with a hollow center, making the data segments look like arcs or rings instead of solid wedges|
|**Area Chart**|is a data visualization that builds on a standard line chart by filling the space between the plotted line and the baseline (usually the x-axis) with color, gradients, or textures |
|**Histogram**| is a type of graph that shows how often numerical (quantitative) data appears within specific ranges or intervals |
